# Local repo workflow (overrides global branch/MR rules)

- This repo is a personal fork (`origin` = `trongnghia203/claude-code-cli-ui`). No upstream PR flow.
- Solo work. No branches, no PRs/MRs, no review step.
- Commit and push directly to `main`. Do not create feature branches, even though the global rule says to branch off the default branch.
- No Jira ticket for this repo, so ticket-based branch naming does not apply.
- Still ask before pushing, unless the user already said to push.
